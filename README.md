### 👨‍💻 About Me:

Hi, I'm Faizan Khan 👋

I'm a Frontend Developer who learns by building. I create clean, responsive, user-focused interfaces with **React, JavaScript, HTML, CSS, Tailwind CSS and Bootstrap**, and I'm currently going full-stack with the **MERN stack** (Node.js, Express.js, MongoDB) and **AI with Python** through DigiSkills Pakistan.
