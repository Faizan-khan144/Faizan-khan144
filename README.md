# 👋 About Me

I'm **Muhammad Faizan Khan**, a frontend developer focused on creating **responsive, modern and user-focused web experiences**.

I work primarily with **HTML, CSS, JavaScript, React and Tailwind CSS**, while expanding into the **MERN stack** with Node.js, Express.js and MongoDB.

I learn by building.

Instead of only following tutorials, I like taking an idea, turning it into a real interface, debugging the problems I encounter and continuously improving the result.

I'm also exploring **Python, NumPy, Pandas and Matplotlib** as part of my journey into Python and AI.
